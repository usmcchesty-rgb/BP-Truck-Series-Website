Track Map Processor

Upload a PNG track map with a white background. The tool removes white/near-white pixels (RGB > 235), keeps dark track lines, adds a 1px white outer stroke, and saves to public/assets/tracks/ using the selected track output filename. Run npm run start, then use this page on the same dev server. File save works in local vercel dev only — commit generated PNGs before deploy.
